Motor Quote Calculator

How to use this tool (quick guide)
  1. Add the vehicles. Use the ribbon: + Add vehicle for a blank one, Copy this vehicle to repeat a class. Each tab keeps its own details.
  2. Fill one vehicle. Registration, make/model, year, then pick the class (tap the box and type a word, e.g. "matatu"), the cover and, for comprehensive, the vehicle value. Answer any extra question that appears (passengers, TPO category, taxi type, payment plan).
  3. Tick the extras. PVT, Excess Protector, Loss of use, COMESA (choose the period and the persons; use 0 persons for a trailer). Covers already in the rate show as "Included".
  4. Fill the header. SN, proposer, location, occupation, intermediary, prepared by and approved by.
  5. Read the quotation. It updates as you type. Fix anything in the yellow warning box first. Red lines on the sheet need action (valuation, declaration of use, Underwriter authorization).
  6. Download PDF (one page, named with the registrations) or Print / Save as PDF. Press Show internal notes to see the workings and observations (staff only).
